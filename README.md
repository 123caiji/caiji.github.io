# 物联网智能家居项目集合

## 项目概述
本仓库包含基于STM32的物联网智能家居和环境监测系统项目，涵盖从硬件设计到软件实现的完整解决方案。

## 项目结构
```
家居/
├── 2.电路图/             # 项目电路图
├── 3.元器件清单/          # 项目所需元器件列表
├── 程序.zip              # 项目源代码
├── HomeInt-main.7z       # 智能家居系统压缩包
├── LoRa_2Nodes_Demo-main.7z  # LoRa环境监测系统压缩包
├── stm32-RTOS-master.7z  # FreeRTOS项目压缩包
└── 物联网（IoT）平台从0到1构建指南 - 完善版.md  # IoT平台构建指南
```

## 主要内容
- **智能家居控制系统**：基于STM32F103的智能家居解决方案，支持多种传感器和远程控制
- **LoRa环境监测系统**：基于LoRa模块的智能环境监测网络
- **FreeRTOS多任务项目**：展示FreeRTOS在STM32上的应用
- **IoT平台构建指南**：从0到1构建物联网平台的详细指南

## 技术栈
- **硬件**：STM32F103系列单片机
- **操作系统**：FreeRTOS（部分项目）
- **通信**：WiFi、MQTT、LoRa、UART、I2C、SPI
- **云平台**：Gizwits、OneNET、EMQX
- **开发工具**：Keil MDK、STM32CubeMX

## 使用说明
1. 查看项目电路图和元器件清单，准备硬件
2. 解压对应项目压缩包，获取源代码
3. 使用Keil MDK打开工程文件，编译并烧录到STM32开发板
4. 参考IoT平台构建指南，搭建配套的物联网平台
