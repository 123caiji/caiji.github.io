# 物联网智能家居项目集合

## 项目文件说明

### 1. 基于STM32的智能家居控制系统
- **路径**：`智能家居/`
- **项目说明**：基于STM32F103系列单片机开发的智能家居控制系统
- **值得关注**：
  - 多种传感器集成与数据处理
  - OLED显示与菜单系统
  - WiFi远程控制与云平台对接
  - 参数阈值设置与存储

### 2. HomeInt-main智能家居系统
- **路径**：`HomeInt-main/`
- **项目说明**：基于STM32和ESP8266的物联网智能家居系统
- **值得关注**：
  - OneNET云平台对接与MQTT通信
  - 本地按键控制与远程云端控制
  - 多种传感器数据采集与执行器控制

### 3. STM32-FreeRTOS项目
- **路径**：`stm32-RTOS-master/`
- **项目说明**：基于FreeRTOS操作系统的STM32项目
- **值得关注**：
  - FreeRTOS多任务调度实现
  - 传感器数据采集任务
  - 电机控制与OLED显示任务

### 4. LoRa_2Nodes_Demo智能环境监测系统
- **路径**：`LoRa_2Nodes_Demo-main/`
- **项目说明**：基于STM32F103C8T6和ATK-LORA模块的智能环境监测系统
- **值得关注**：
  - 双LoRa节点网络构建
  - FreeRTOS任务管理
  - MQTT协议数据上传
  - Android App远程监控

### 5. 物联网平台构建指南
- **路径**：`物联网（IoT）平台从0到1构建指南 - 个人学习笔记.md`、`物联网（IoT）平台从0到1构建指南 - 完善版.md`
- **项目说明**：物联网平台构建的学习笔记和指南
- **值得关注**：
  - IoT平台需求分析与技术选型
  - 设备端、平台端、应用端功能设计
  - 实际开发中的踩坑记录与解决方案

## 技术栈
- **硬件平台**：STM32F103系列单片机
- **操作系统**：FreeRTOS（部分项目）
- **通信协议**：WiFi、MQTT、LoRa、UART、I2C、SPI
- **云平台**：Gizwits、OneNET、EMQX
- **开发工具**：Keil MDK、STM32CubeMX
